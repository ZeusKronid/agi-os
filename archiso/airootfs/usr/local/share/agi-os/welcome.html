AGI OS

Tell the agent what kind of system you want.

  1. Connect to the internet using the network icon on the panel. Ethernet connects automatically.
  2. Select Sign in with ChatGPT in the open Codex terminal. The login page will open here in Firefox. Sign in to your account.
  3. Return to the terminal and describe the system you want. The agent will perform the installation.

To reopen the agent, use Applications → System → Codex, or run codex in a terminal.
